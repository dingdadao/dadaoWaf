证书列表

证书按域名（SAN / CN）自动匹配 SNI，未匹配的请求使用默认证书。HTTPS 监听需要至少一张证书。 从雷池同步的 ACME 证书只登记证书链，会标记「缺私钥」，补传私钥后才可用于 TLS。

上传证书

支持 RSA / ECDSA。私钥只保存在本机数据库，不会通过列表接口返回。编辑时私钥留空表示沿用原私钥。

第三方证书推送（Certd / 雷池兼容）

Certd：新建「长亭雷池授权」，地址填本机管理地址 （如 http://10.0.0.31:9443），ApiToken 填下方这个 HomeWAF API Token； 流水线中添加「雷池-更新证书」，证书 ID 选 0 表示新增，或选已有证书做续期。 这里用的不是「系统设置 → 雷池同步」里的雷池 Token。
雷池开放接口：GET /api/open/health、GET /api/open/cert、 GET /api/open/cert/{id}、POST /api/open/cert （JSON：{"manual":{"crt","key"}}，同域名自动按续期更新）、 DELETE /api/open/cert/{id}。
也兼容：POST /api/UploadSSLCertAPI（multipart：crt_file / key_file / name / id）、 GET /api/CertAPI、DELETE /api/CertAPI。 请求头统一为 X-SLCE-API-Token；雷池「配置同步」把从节点指向本机时也用这套接口。
重新生成后旧 Token 立即失效。尚未生成 Token 时，第三方接口一律返回 401； 第三方脚本只需把证书与私钥 POST 到本机管理端口即可完成部署。

黑白名单

白名单 0 黑名单 0 人机验证 / 仅记录 0
这个页面是干嘛的

按请求本身（源 IP、路径、Host、User-Agent、请求头、查询参数）直接处置请求， 不做内容特征匹配、不参与计分。适合「只让内网访问后台」「拉黑某个来源」这类按来源或入口做的管控。

  • 规则类型：白名单 = 命中直接放行，并跳过后续所有检测与封禁；黑名单 = 命中直接拦截；人机验证 = 要求过验证；仅记录 = 只记事件不拦。
  • 匹配方式：任意 = 满足任一个条件组即可；全部 = 所有条件组都要满足；组内多个条件始终是「且」。
  • 生效应用：可多选，不选 = 对所有应用生效。
  • 匹配条件：字段 + 运算符 + 值。IP 组来自「订阅源」里类型为 IP 组的订阅。
  • 规则 ID：创建时自动生成，之后不能改（雷池同步来的形如 lei-acl-*）。
  • 序号越大越新，匹配时从新到旧。

检测白名单（误报豁免）

这个页面是干嘛的

用来消除误报：正常业务请求被检测规则拦了，在这里给它开豁免， 而不用把整类检测关掉。只影响内容检测（内置规则、订阅规则、检测黑名单）， 不影响黑白名单的放行与拦截。

  • 应用 / 路径前缀 / 只豁免某条规则：三个条件同时满足才生效；至少要填一个， 全空等于对所有请求关闭全部检测，很危险。
  • 路径前缀：按前缀匹配，必须以 / 开头。填 /admin/editor 会同时命中 /admin/editor/post，但不会命中 /public/admin/editor。
  • 只豁免某条规则：选具体规则 = 只跳过这一条；留空 = 跳过该范围内的全部检测。
  • 举例：博客后台提交 HTML 正文老被 XSS 规则误拦 → 应用选「博客」、路径填 /admin/editor、规则选那条 XSS 规则。

检测黑名单（自定义检测规则）

这个页面是干嘛的

用来补内置规则覆盖不到的内容特征：写一条正则，命中后按分值计分（默认累计到 50 分就拦）， 并参与自动封禁。典型场景是新漏洞（如 PHP2Shell）刚曝光、规则包还没更新时，先自己加一条。

  • 正则：作用于归一化后的内容（URL 解码、HTML 实体还原、Unicode 折叠、去 SQL 注释、转小写），所以正则要写小写，不要再加 (?i)。
  • 预过滤关键词：填正则里必然出现的小写词（如 union），内容只有含它才会跑正则，能显著降低开销。
  • 作用对象：在哪些位置匹配 —— 路径 / 查询参数 / 请求体 / 请求头 / Cookie / User-Agent，可多选。
  • 分值：low 10 / medium 25 / high 50 / critical 80；累计到拦截阈值（默认 50）才拦。
  • 动作：拦截 = 命中即拦，不等阈值；仅记录 = 只记事件。
  • 备注：写清楚为什么加、对应哪个漏洞，方便日后排查。

和「黑白名单」的区别：这里匹配请求内容、要跑正则、参与评分；黑白名单匹配请求元数据，直接放行或拦截。
