# 功能差距统计

> 对照雷池（SafeLine）的功能矩阵，逐项统计 HomeWAF 的实现状态。
>
> 最后更新：2026-10-22

## 总览

| 状态 | 数量 | 说明 |
|---|---|---|
| ✅ 已实现 | 38 项 | 可用，有测试覆盖 |
| 🟡 部分实现 | 5 项 | 有结构/部分能力，缺关键环节 |
| ⬜ 未实现 | 20 项 | 完全没有 |

按 PRD 263 条功能需求算，**实际覆盖约 57%**。
本轮补齐了 CC 防护、应用/路由级策略、人机验证、规则包订阅，以及概览趋势、攻击分类和事件 CSV 导出。

## 四、建议顺序

按「投入产出比」排：

| 顺序 | 功能 | 理由 |
|---|---|---|
| 1 | **登录页** | 控制台现在无认证，只能靠回环地址保护 |
| 2 | **ACME** | 证书续期是真实痛点 |
| 3 | **告警通知** | 被打时用户需要第一时间知道 |
| 4 | **攻防地图** | 趋势与分类已有，地图属于锦上添花 |
| 5 | **多证书 SNI** | 多域名多证书场景才需要 |
| 6 | **语义分析** | 投入大，先用规则 + 白名单控制误报 |

前 3 项约 7 人日。

## 五、和雷池的差距

| 维度 | 雷池 | HomeWAF |
|---|---|---|
| 检测方式 | 语义分析 + 规则 | 纯规则（41 条，17 类） |
| 规则更新 | 官方规则包自动更新 | Ed25519 签名规则包，定时更新 + 影子期 |
| CC 防护 | 完整 | 三层限流 + 并发连接 + 人机验证 |
| Bot 防护 | JA4 指纹 + 人机验证 | 人机验证；无 JA4 指纹 |
| 证书 | 内置 Let's Encrypt | 手动 |
| 概览 | 攻防地图 + 趋势 | 24 小时趋势 + 攻击分类（无地图） |
| 部署 | Docker 一键 | 单二进制 |
| 资源占用 | 较重（语义分析模型） | 轻（41 条正则） |

**我们的优势**：单二进制、无依赖、资源占用低、配置在数据库里可控。
**我们的劣势**：检测以正则为主、缺 Bot 指纹与自动证书、运维功能少。
